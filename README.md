# Collab Tool

A full-stack project management app based on the task brief: group projects, task assignment, task comments, authentication, project boards, task cards, notifications, and real-time updates with WebSockets.

## Run

```bash
npm install
npm run dev
```

Open http://127.0.0.1:3000.

Demo account:

```text
demo@example.com
password123
```

New users can also register from the sign-in screen.
